OSS Evidence Kit

Generate concise, verifiable public evidence reports for open-source maintainers applying for grants, credits, sponsorships, and maintainer-support programs.

GitHub Application Notes 
$ oss-evidence-kit report \
  --repo owner/name \
  --out docs/reviewer-evidence.md

Collects public GitHub evidence:
  releases
  issues and pull requests
  contributors
  license and community files
  stars, forks, watchers

Outputs reviewer-friendly Markdown.

Public by default

Uses public GitHub metadata and avoids private repository scraping or hidden claims.

Reviewer friendly

Turns scattered maintenance signals into one Markdown report that can be checked quickly.

Abuse aware

Explicitly rejects fake stars, star swaps, fabricated users, and unverifiable impact claims.
