# Contributing

Thank you for improving OSS Evidence Kit.

The project favors small, reviewable changes:

1. keep the CLI dependency-free unless there is a strong reason;
2. prefer public, verifiable evidence over subjective claims;
3. add tests for parsers, scoring, and report formatting;
4. document abuse risks for new adoption signals;
5. never add tokens, cookies, or private repository data to examples.

## Local check

```bash
npm run check
```

## Good first issues

1. Add another report section for GitHub Discussions.
2. Add a JSON output mode.
3. Add a GitHub Action example.
4. Improve wording for non-English maintainers.
